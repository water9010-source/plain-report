# 給 AI 的白話回報規則 Plain Report — Claude Skill

AI 的回報常常又長又滿是專業詞，看完還是不知道到底做好了沒有。這個 Skill 讓 AI 用白話回報：先講結果，只答你問的，已做、沒做、要你決定的分開寫。

## 怎麼用
- 先講結果，再講必要的細節；只回答現在問的事，不延伸新工作。
- 少用專業詞，非用不可時第一次出現就用一句白話解釋；比較時用「原本／修改後／差別」表格。
- 已完成、沒完成、要你決定的分開寫；沒實際測過就不說改善了。

## 限制
- 還沒有實際使用紀錄。
- Skill 內容是繁體中文。
- 不保證一定有效；AI 不一定每次都照做。
